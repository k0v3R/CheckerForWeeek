# Политика конфиденциальности

Расширение **Checker for Weeek** (далее — «расширение») — неофициальный клиент уведомлений сервиса [app.weeek.net](https://app.weeek.net). Эта политика описывает, какие данные обрабатывает расширение. Она написана для пользователей и для карточек в магазинах расширений (Microsoft Edge Add-ons, Chrome Web Store и аналогичных).

> **EN summary:** This extension has no analytics, no telemetry and no own servers. It talks only to `api.weeek.net` and `app.weeek.net` using your existing Weeek session cookies. Settings and the cached notification list are stored locally in the browser. The developer receives nothing.

- Дата последнего обновления: 2026-11-17
- Версия расширения: 1.0.0

## Кратко

- Расширение **не имеет аналитики, телеметрии и собственных серверов**.
- Данные не отправляются разработчику и каким-либо третьим лицам.
- Сетевые запросы выполняются **только** к `api.weeek.net` и `app.weeek.net`.
- Отдельной авторизации нет: расширение использует вашу обычную сессию сайта. Оно **не запрашивает и не хранит** логин и пароль.

## Какие данные обрабатываются

### Данные, которые расширение читает у вас в браузере

| Данные | Зачем | Где хранится |
|---|---|---|
| Сессионные cookies домена `api.weeek.net` | Выполнять запросы к API от вашего имени (как это делает сам сайт) | Остаются в браузере; расширение не копирует их в другое место |
| Cookie `XSRF-TOKEN` домена `api.weeek.net` | Передавать CSRF-токен в заголовке `X-XSRF-TOKEN` при POST/DELETE — так же, как делает сайт | Остается в браузере |
| Ответы API: список непрочитанных уведомлений (название задачи, автор, текст, путь «Проект > Доска > Колонка», время) | Показать список в попапе, бейдж со счётчиком, системные тосты | `chrome.storage.session` — только на время сессии браузера |
| Настройки: интервал опроса, тема, звук, тосты, путь до задачи | Работать в соответствии с выбором пользователя | `chrome.storage.sync` — синхронизируется браузером между устройствами, если включена синхронизация браузера |

### Данные, которые расширение НЕ собирает

- Не собирает логины, пароли или bearer-токены (кроме чтения CSRF-cookie `XSRF-TOKEN` для подписи запросов, как это делает сам сайт Weeek).
- Не собирает историю просмотров, данные других сайтов, контакты, файлы, геолокацию.
- Не использует аналитические сервисы (Google Analytics, Яндекс.Метрика и т.п.).
- Не отправляет данные на серверы разработчика — таких серверов нет.

## Разрешения расширения

| Разрешение | Зачем нужно |
|---|---|
| `alarms` | Планировать периодическую проверку непрочитанных уведомлений |
| `storage` | Хранить настройки и кэш уведомлений локально |
| `cookies` | Читать сессионные cookies и `XSRF-TOKEN` **только** домена `api.weeek.net` для авторизованных запросов |
| `offscreen` | Воспроизводить собственный звук уведомления из service worker (ограничение Manifest V3) |
| `notifications` | Показывать системные тосты Windows при новых уведомлениях |
| `host_permissions`: `https://api.weeek.net/*`, `https://app.weeek.net/*` | Обращаться только к API и открывать задачи на сайте |

## Кому передаются данные

Только сервису Weeek (`api.weeek.net`, `app.weeek.net`) — в объёме, необходимом для получения списка уведомлений, пометки прочитанным и архивирования. Эти запросы выполняются с вашими cookies так же, как если бы вы пользовались самим сайтом.

Обработчики данных — вы сами (локально в браузере) и сервис Weeek (к данным на его стороне применяется его собственная политика конфиденциальности). Разработчик расширения не получает доступ к вашим уведомлениям, cookies или настройкам.

## Использование API

Публичный API (`api.weeek.net/public/v1`) не содержит эндпоинтов уведомлений, поэтому расширение использует cookie-авторизованный API `api.weeek.net`. Формат этого API не документирован и может измениться. Пользователь устанавливает и использует расширение на свой риск.

## Дети

Расширение не ориентировано на детей и не собирает данные о детях.
